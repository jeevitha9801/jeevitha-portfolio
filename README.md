# Jeevitha Portfolio

A personal portfolio website showcasing my professional experience, technical skills, projects, achievements, and educational background as a Software Engineer.

## 🚀 Tech Stack

- React
- Vite
- JavaScript
- HTML
- CSS

## ✨ Features

- Professional Profile & About Me
- Technical Skills Showcase
- Work Experience Timeline
- Featured Projects
- Education
- Achievements & Awards
- Resume Download
- Contact Information
- Responsive Design

## 📂 Featured Projects

- Scalable Event-Driven Notification System
- E-Commerce Inventory Management System
- API Gateway & Rate Limiter
- URL Shortener Platform
- Full-Stack E-Commerce Platform
- Pathfinding Visualizer

## 🛠️ Run Locally

```bash
npm install
npm run dev
```

## 📦 Build for Production

```bash
npm run build
```
